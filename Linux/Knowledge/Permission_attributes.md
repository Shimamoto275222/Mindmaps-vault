
### Table 9-2: Permission Attributes

| Attribute | Files                                                                                                                                                                                                                                | Directories                                                                                                                                                                                             |
| :-------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **r**     | Allows a file to be opened and read.                                                                                                                                                                                                 | Allows a directory's contents to be listed,<strong style="color: red;"> but no file information is available unless the execute attribute is also set. </strong>                                        |
| **w**     | Allows a file to be written to or truncated, however <strong style="color: red;">this attribute does not allow files to be renamed or deleted</strong>. The ability to delete or rename files is determined by directory attributes. | Allows files within a directory to be created, deleted, and renamed <strong style="color: red;">if the execute attribute is also set. </strong>                                                         |
| **x**     | Allows a file to be treated as a program and executed. <strong style="color: red;">Program files written in scripting languages must also be set as readable to be executed </strong>.                                               | Allows a directory to be entered (i.e., `cd directory`) and directory metadata (i.e, `ls -l directory`) to be accessed. File operations such `cp`, `rm`, and `mv` require this access to the directory. |
